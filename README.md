# blesk

Конфиденциальный мессенджер для Android: личные чаты, группы и каналы, комнаты с текстовыми
и голосовыми каналами. Личные чаты, группы и закрытые комнаты всегда шифруются сквозным
шифрованием (libsignal).

Сборка: JDK 21, Android SDK (`scripts/setup-android.sh`), затем `./gradlew :app:assembleDebug`.
