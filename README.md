# blesk

Конфиденциальный мессенджер для Android: личные чаты, группы и каналы, комнаты с текстовыми
и голосовыми каналами. Личные чаты, группы и закрытые комнаты всегда шифруются сквозным
шифрованием (libsignal).

Сборка: JDK 21, Android SDK (`scripts/setup-android.sh`), затем `./gradlew :app:assembleDebug`.

Лицензия — AGPL-3.0 (`LICENSE`). Шрифт Onest — SIL Open Font License 1.1.

## Подлинность сборок

Встроенное обновление ставит только APK, подписанный тем же ключом, что и установленное приложение, и только если его SHA-256 совпадает со строкой «SHA-256 APK» в описании релиза. В приложении: «Настройки → О приложении → Подлинность» показывает отпечаток ключа подписи этой копии.

| Ключ | SHA-256 сертификата подписи |
|---|---|
| Тестовый (лежит в репозитории, подписать им может кто угодно) | `bd7e78024ea47ca7e7de70c02c39beff5a2855be35560288cdd477e57f9d78bd` |
| Официальный | будет опубликован здесь, когда владелец создаст ключ |

Если отпечаток в приложении не совпадает ни с одним из этих — это не наша сборка.
