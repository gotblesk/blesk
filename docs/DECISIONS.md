# Решения

Формат: дата — решение — причина.

- 2026-10-11 — Прежний проект (Electron-клиент, Node-сервер, макеты) перенесён в `legacy/`, а не удалён. — Бриф описывает новое Android-приложение; старый код и макеты владельца остаются под рукой как справка.
- 2026-10-11 — Разработка идёт в ветке `claude/file-review-0lky6f`; CI собирает релизы и с неё, и с `master`. — Сессии разрешён push только в эту ветку, а владелец должен получать APK без слияния.
- 2026-10-11 — Пакет и applicationId — `app.blesk`. — `fun` из домена blesk.fun — ключевое слово Kotlin и неудобно в именах пакетов.
- 2026-10-11 — AGP 9.4 со встроенным Kotlin, Kotlin 2.4, Gradle 9.8, compileSdk/targetSdk 37, minSdk 26. — Последние стабильные версии на дату старта.
- 2026-10-11 — Внедрение зависимостей вручную (`AppContainer`), без Hilt. — Меньше генерации кода и времени сборки; граф пока маленький.
- 2026-10-11 — Навигация на Navigation 3. — Compose-нативный back stack без Material-зависимостей.
- 2026-10-11 — Скриншот-тесты на Roborazzi + Robolectric (SDK 36). — Работают в обычных юнит-тестах без эмулятора; Robolectric пока не поддерживает SDK 37.
- 2026-10-11 — detekt 1.23.8 (последний стабильный) с formatting-правилами. — detekt 2.0 ещё в альфе.
- 2026-10-11 — Фон темы не может быть средне-серым: тёмный не светлее L 0.40, светлый не темнее L 0.80 (OKLCH). — На среднем фоне текст не достигает 4.5:1 ни белым, ни чёрным; так автоматическая подстройка контраста всегда срабатывает.
- 2026-10-11 — Отчёт о сбое хранит только классы исключений и стек, без сообщений исключений. — Сообщение исключения может процитировать текст пользователя.
- 2026-10-11 — Модули `:core:crypto`, `:core:network`, `:core:media` и сервер создаются на своих этапах (3–4), а не пустыми заранее. — Пустые модули ничего не дают и тормозят сборку.
- 2026-10-11 — Демо-мир живёт только в памяти и пересоздаётся при запуске. — Демо не должно оставлять на телефоне ничего похожего на настоящую переписку.
- 2026-10-11 — Аватары до загрузки фото — монограмма (первая буква на матовом круге). — Стоп-лист запрещает сгенерированные картинки и заглушки.
- 2026-10-11 — Иконка приложения — капсула с бликом по краю, нарисована векторно. — Белый блеск — главный знак blesk; без сгенерированных изображений.
- 2026-10-11 — Коммиты подписаны автором `gotblesk`, как и прежняя история репозитория. — Бриф требует отсутствия следов ассистента.
