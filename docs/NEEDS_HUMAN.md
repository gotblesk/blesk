В репозитории (сейчас `legacy/restart_server.py` и `legacy/test_smtp.py`, раньше — в корне)
лежат открытым текстом пароль root от сервера 83.222.16.169 и пароль почты noreply@blesk.fun.
Они есть и в истории git, поэтому удаление файлов их не спрячет.

1. Зайдите в панель хостинга сервера (где покупали VPS) с телефона.
2. Найдите сервер 83.222.16.169 → «Сменить пароль root» (или «Доступ» → «Пароль»). Задайте новый длинный пароль.
3. Зайдите в панель Beget (почта blesk.fun) → «Почта» → noreply@blesk.fun → «Сменить пароль».
4. Новые пароли никуда в репозиторий не пишите. Для деплоя позже понадобится только SSH-ключ (пункт 2).
5. Напишите мне «пароли сменил» — я удалю эти два файла из репозитория.

## 2. Свой сервер (нужен, чтобы переписываться по-настоящему)

Без сервера приложение работает в демо-режиме. Чтобы два телефона переписывались, нужен VPS.

1. Купите VPS: Ubuntu 24.04, процессор x86_64 (не ARM), 2 ГБ памяти, 20 ГБ диска. Подойдёт любой хостер; домен не обязателен.
2. Поставьте на телефон приложение для SSH — Termius (Android, бесплатно).
3. В Termius: «+» → New Host → Address: IP сервера, Username: root, Password: пароль от хостера → Save → нажмите на сервер.
4. Вставьте одну строку и нажмите Enter:

```
curl -fsSL https://raw.githubusercontent.com/gotblesk/blesk/claude/file-review-0lky6f/scripts/deploy.sh | sudo BLESK_BRANCH=claude/file-review-0lky6f bash
```

5. На вопрос про домен просто нажмите Enter (если домена нет).
6. Подождите 5–10 минут. В конце появится QR-код.
7. Если у хостера в панели управления есть свой файрвол — откройте в нём порты для звонков: **7881** (TCP) и **50000–50100** (UDP). Без них переписка работает, а звонки не соединятся.
8. В blesk: Настройки → Сервер → «Сканировать QR» → наведите камеру на QR-код → придумайте имя пользователя → «Создать аккаунт».
9. На втором телефоне сделайте то же самое (шаг 8) с другим именем. Найдите друг друга во вкладке «Контакты».

Когда ветка будет слита в master, команда станет короче — она есть в `docs/SERVER.md`.

## 3. Проверка перед версией 1.0 (два телефона и сервер из пункта 2)

Пройдите по списку и напишите мне, что не сработало (можно скриншотом):

1. Написать друг другу, отправить фото, голосовое и кружок.
2. Видеозвонок: позвонить со второго телефона, когда на первом приложение закрыто (включите на нём Настройки → Уведомления → «Всегда на связи»).
3. Создать комнату, зайти обоими в голосовой канал, поговорить; показать экран.
4. В личном чате «i» → Проверка ключей: отсканировать QR друг у друга — должно быть «Коды совпали».
5. Включить исчезающие сообщения на 1 час и проверить, что метка «исчезают: 1 час» появилась у обоих.
6. Создать канал (кнопка «+» на вкладке «Чаты» → «Канал»), найти его со второго телефона во вкладке «Контакты».
7. Настройки → Боты → создать бота; запустить пример из `examples/echo_bot.py` на компьютере или сервере (инструкция в `docs/BOT_API.md`) и написать ему.

## 4. По желанию: обновление сервера кнопкой из GitHub

Нужно, чтобы обновлять сервер без Termius: GitHub → Actions → Deploy server → Run workflow.

1. В Termius на сервере выполните: `ssh-keygen -t ed25519 -N "" -f ~/.ssh/blesk_deploy && cat ~/.ssh/blesk_deploy.pub >> ~/.ssh/authorized_keys && cat ~/.ssh/blesk_deploy`
2. Скопируйте весь показанный текст (от `-----BEGIN` до `-----END ... KEY-----`).
3. На github.com откройте репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   - `VPS_SSH_KEY` — вставьте скопированный текст;
   - `VPS_HOST` — IP сервера;
   - `VPS_USER` — `root`.
4. Напишите мне «секреты добавил».
