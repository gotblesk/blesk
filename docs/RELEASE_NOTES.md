## 0.4 — медиа

- Фото и видео из галереи: у фото стираются данные о месте и камере, видео сжимается.
- Файлы до 200 МБ, открываются другим приложением по нажатию.
- Голосовые: удерживайте микрофон; вверх — запись без рук, влево — отмена. Волна, перемотка, скорость 1x / 1.5x / 2x.
- Кружки: коротко нажмите на микрофон, чтобы переключиться на камеру, и удерживайте.
- Фото открываются на весь экран с увеличением, видео — с перемоткой.
- Бот-эхо возвращает и медиа.
