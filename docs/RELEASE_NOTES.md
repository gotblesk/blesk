## 0.5 — сервер и сквозное шифрование

- Свой сервер: установка одной командой на VPS, подключение по QR-коду.
- Регистрация только по имени пользователя, без телефона.
- Личные чаты шифруются протоколом Signal с постквантовой защитой (PQXDH + Kyber).
- Доставлено и прочитано, реакции, правка и удаление у всех, «печатает».
- Фото, видео, файлы, голосовые и кружки уходят зашифрованными.
- Сообщения не теряются без сети: отправятся, когда связь вернётся.
- Демо-режим работает как раньше, пока сервер не подключён.
