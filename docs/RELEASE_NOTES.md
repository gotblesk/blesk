## 0.7 — звонки

- Аудио- и видеозвонки один на один: кнопки в шапке личного чата.
- Голосовые каналы в комнатах: зайти, говорить, видеть, кто говорит.
- Демонстрация экрана во время звонка.
- Входящий звонок будит экран и показывается поверх блокировки; ответить и отклонить можно прямо из уведомления.
- Звук и видео шифруются на телефонах ключом, который передаётся только через защищённую переписку. Сервер звонков прослушать разговор не может.
- В демо звонок никуда не уходит: на экране видна только ваша камера.
