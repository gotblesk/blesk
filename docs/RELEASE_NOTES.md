## 0.8 — боты, уведомления, проверка ключей

- Боты: найдите бота по имени во вкладке «Контакты» (имя оканчивается на _bot). Кнопки под сообщениями бота, подсказки команд при вводе «/». Чаты с ботами матовые и подписаны «бот · без шифрования».
- Свои боты: Настройки → Боты. Токен показывается один раз. Как написать бота — в docs/BOT_API.md, там же пример.
- Уведомления о сообщениях: по умолчанию видно только, от кого сообщение. Настройки → Уведомления.
- Режим «Всегда на связи»: сообщения и звонки приходят, даже когда приложение закрыто.
- Проверка ключей: в личном чате — значок щита. 60 цифр и QR-код; если ключ собеседника изменится, чат предупредит.
- В демо у бота «Эхо» появились кнопки: напишите ему /start.
