# Ключ подписи — только для тестовых сборок

`blesk-test.jks` подписывает тестовые APK из CI, чтобы обновления ставились поверх
без потери данных. Ключ и пароль (`blesk-test-only`) открыты, поэтому этим ключом
нельзя подписывать боевые сборки. Боевой ключ появится после v1.0 и будет храниться
в секретах GitHub, а не в репозитории.
